SECTION XX // CARD BACKSIDE VISIBILITY IN MINI DECK MODE

Overview: In UNO Flip mini deck mode, each player’s hand is displayed with both faces of each card visible to the owner, allowing strategic planning based on the light and dark side values. Additionally, opponents can see the back side of each other's cards, mirroring the physical game where card backs are visible.

Gameplay Impact:
- Players can preview the dark‑side action (e.g., Draw Five, Skip) while holding a card, aiding decision‑making before a flip.
- Opponent’s card backs are revealed, enabling anticipation of potential flips and defensive plays.

Implementation Note: The client renders a dual‑face UI component that flips on hover or tap for the owner’s cards, while opponent cards display a static backside sprite representing the dark side.

SECTION 03 // GAME ENGINE & TURN EXECUTION
Authoritative Game Engine Mechanics
Deterministic state transition pipeline, strict rule enforcement, and cryptographic shuffling.
SERVER-AUTHORITATIVE PARADIGM
The game engine operates under a strict server-authoritative
architecture implemented in server/src/engine/rules.js  and
game.js . Clients are untrusted visual terminals. When a player plays a
card, only the card identifier and selected wild color are transmitted.
The server executes a seven-stage deterministic validation pipeline:
1. Turn Verification: Asserts currentPlayerId ===
socket.playerId .
2. Ownership Check: Verifies card exists in server-side player hand.
3. Face Resolution: Resolves active face corresponding to current
activeSide .
4. Number-Card Victory Law: Rejects action cards if hand count is 1.
5. Draw Attack Enforcement: Rejects non-draw plays if under active
attack.
6. Compatibility Match: Validates color, value, type, or Wild match.
7. Wild Color Verification: Validates chosen color against active side
palette.

STRICT OFFICIAL RULE INVARIANTS
1. The Number-Card Victory Law
Under official Mattel tournament rules, a player cannot finish a match on
an action or wild card ( SKIP , REVERSE , FLIP , DRAW_ONE ,
DRAW_FIVE , WILD , WILD_DRAW_COLOR ). The winning play must be a
standard Number Card (1–9). If a player attempts to play a power card as
their last remaining card, the engine rejects the move with code
LAST_CARD_MUST_BE_NUMBER .
2. Strict UNO Shouting Conditions
The UNO button is strictly guarded by server logic. It is enabled only
when: (a) It is currently the player's active turn; (b) The player holds exactly
2 cards in hand; and (c) The player possesses at least one legally playable
card. Premature or out-of-turn UNO shouting is blocked by client and
rejected by server.
CRYPTOGRAPHIC FISHER-YATES DECK RESHUFFLING
When the draw pile is exhausted, the engine reshuffles the discard pile (excluding the top card) using Node.js's cryptographic random byte
generator to prevent predictability or pseudo-random repetition:
function shuffleDeck(deck) {
  const result = [...deck];
  for (let i = result.length - 1; i > 0; i--) {
    // Generate uniform cryptographic random 32-bit unsigned integer
    const randomUint32 = crypto.randomBytes(4).readUInt32LE(0);
    const j = Math.floor((randomUint32 / 0xFFFFFFFF) * (i + 1));
    [result[i], result[j]] = [result[j], result[i]];
  }
  return result;
}

SECTION 04 // THE FLIP MECHANIC & DRAW STACKING
The FLIP Inversion & Draw Stacking
Global tabletop state inversion, progressive penalty stacking algorithms, and dark side power cards.
THE GLOBAL FLIP INVERSION LIFECYCLE
Playing any FLIP  card triggers an instantaneous tabletop inversion:
Active Side Toggle: activeSide  flips from LIGHT  to DARK  (or
vice versa).
Discard Stack Inversion: The active face of the top discard card
immediately becomes its reverse face. The newly exposed color and
action dictate subsequent plays.
Draw Pile Flip: The draw pile is turned over. The cards on the reverse
side become active for subsequent draws.
Player Hand Inversion: All players' physical cards reveal their
opposite faces. What was previously a Light Blue 3 may now be a Dark
Purple Skip Everyone!
DUAL-SIDED ARENA VISUAL COMPARISON
Light Side: Classic Primary Palette
Dark Side: Cyberpunk Neon Palette

Stacking Rules & Degradation Block:
No Downgrading: A player under a +2 attack cannot counter with a +1

Card Lockdown: Non-draw cards cannot be played while under attack.
Accumulation: If three +5 cards are chained consecutively, the unfortunate
fourth player draws 15 cards and loses their turn!
SPECIAL DARK SIDE ACTION CARDS DEEP DIVE
Skip Everyone (SKIP_EVERYONE)
Unlike standard Skip which skips only the immediate next player, Skip
Everyone skips every single opponent around the table. The turn
immediately loops back to the player who played the card, granting them
an immediate consecutive play.
Wild Draw Color (WILD_DRAW_COLOR)
The player declares a dark side color. The victim player is compelled to
continuously draw cards from the draw pile until they draw a card
matching the declared color. There is no upper bound; a victim may draw
1 card or 15+ cards before matching!

SECTION 05 // REAL-TIME WEBSOCKET PROTOCOL
Real-Time WebSocket Protocol
Sub-millisecond state replication, zero-cheating information hiding, and socket lifecycle.
ZERO-CHEATING INFORMATION HIDING
Many web games leak opponent hands by transmitting full game state
objects over WebSockets. UNO Flip implements an uncompromising
zero-information leakage architecture in
server/src/sockets/gameSocket.js :
Public Board Broadcast: Broadcasted to all room participants. Contains
room ID, active side, top discard card, active player ID, turn direction,
and player metadata with hand card counts only.
Private Hand Unicast: The actual card objects ( id , lightSide ,
darkSide ) are emitted strictly to the authenticated socket of the
individual player.

SOCKET DISCONNECT & SESSION RECOVERY
When a client socket disconnects mid-match, the room manager retains the seat for a 45-second grace period. If the player reconnects with their
persistent playerId  token, their socket is re-bound, and their private hand is re-synchronized immediately. If the grace period expires, an
autonomous AI bot assumes control of the seat to preserve match continuity for remaining players.

BOT ARCHITECTURE & INTEGRATION
The AI Bot system ( server/src/engine/ai.js  and client worker
aiWorker.js ) powers solo offline play and backfills unfilled
multiplayer lobbies. Bots participate as first-class player entities
governed by the same authoritative rules as humans.
Cognitive Principles:
No Cheating Guarantee: Bots inspect only their own hand and public
discard top. They have zero access to opponent cards.
Humanized Response Timing: Decisions pass through
botThinkDelay()  (600ms–1800ms) with normal distribution jitter to
simulate human thought rhythm.
Autonomous UNO Calling: Evaluates hand size on turn end and
triggers UNO shouts dynamically.

On HARD  difficulty, each legal card in the bot's hand is evaluated through a multi-variable scoring function:
function evaluateCardScore(card, face, gameState, hand) {
  let score = 0;
  
  // 1. Threat Mitigation: If next player has <= 2 cards, prioritize attack cards
  const nextPlayerHandSize = getNextPlayerCardCount(gameState);
  if (nextPlayerHandSize <= 2) {
    if (face.type === CARD_TYPE.DRAW_FIVE) score += 95;
    if (face.type === CARD_TYPE.SKIP_EVERYONE) score += 90;
    if (face.type === CARD_TYPE.DRAW_TWO || face.type === CARD_TYPE.DRAW_ONE) score += 80;
    if (face.type === CARD_TYPE.SKIP || face.type === CARD_TYPE.REVERSE) score += 70;
  }
  // 2. Color Dominance: Favor cards matching the bot's most populous color
  const colorCount = hand.filter(c => getActiveFace(c, gameState.activeSide).color === face.color).length;
  score += colorCount * 12;
  // 3. FLIP Tactics: If opponents have few cards and current side has few attacks, flip!
  if (face.type === CARD_TYPE.FLIP && opponentsHaveFewerCards(gameState, hand)) {
    score += 85;
  }
  // 4. Wild Preservation: Penalize early playing of Wild cards if standard matches exist
  if (face.type === CARD_TYPE.WILD || face.type === CARD_TYPE.WILD_DRAW_FOUR) {
    score -= 40; // Save for emergencies
  }
  // 5. Final Card Preparation: Ensure bot preserves a Number Card for the final play
  if (hand.length === 2 && face.type === CARD_TYPE.NUMBER) {
    // Playing the number card now leaves an action card, violating the Number Card Victory Rule!
    score -= 200; 
  }
  return score;
}

SECTION 11 // AUTHENTICATION, CRYPTOGRAPHY & SECURITY
Cryptographic Security & Anti-Cheat
PBKDF2 key derivation offloaded to libuv worker threads, timing-safe authentication, and anti-cheat.
ASYNCHRONOUS MULTITHREADED
AUTH
Security operations must never freeze the real-time
game loop. In server/src/services/authCrypto.js ,
password hashing utilizes PBKDF2 with SHA-512
(100,000 iterations).
libuv Worker Offloading:
Because Node.js's asynchronous crypto.pbkdf2
delegates computation directly to the background
libuv  thread pool, heavy password verification never
occupies the primary V8 event loop. WebSocket frame
rates and game actions maintain sub-millisecond latency
even during sudden spikes in login traffic.
TIMING-SAFE CONSTANT-TIME VERIFICATION
Standard string comparisons ( hashA === hashB ) leak information through variable
execution time, exposing the server to side-channel timing attacks. UNO Flip validates
credentials using constant-time buffer comparison:
function verifyPassword(password, salt, storedHashHex) {
  return new Promise((resolve, reject) => {
    crypto.pbkdf2(password, salt, 100000, 64, 'sha512', (err, key) => {
      if (err) return reject(err);
      const computedBuffer = key;
      const storedBuffer = Buffer.from(storedHashHex, 'hex');
      
      // Constant-time comparison eliminates timing exploits
      if (computedBuffer.length !== storedBuffer.length) return resolve(false);
      const isValid = crypto.timingSafeEqual(computedBuffer, storedBuffer);
      resolve(isValid);
    });
  });
}

Every registered player and guest is assigned an alphanumeric Unique Player ID (e.g., UNO-7821 , UNO-9K2L ). Identifiers are generated using

characters like 0, O, 1, I) to eliminate collision risks and user transcription errors.
